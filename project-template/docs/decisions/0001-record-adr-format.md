# ADR-0001: Record ADR format

## Status

Accepted (template)

## Context

Portfolio yêu cầu quyết định kiến trúc quan trọng được ghi lại thay vì suy diễn trong code.

## Decision

Dùng ADR markdown trong `docs/decisions/` với template trong README của thư mục này.

## Consequences

- Agent và dev tra cứu trước thay đổi lớn.
- ADR mới khi override engineering-standards portfolio.
