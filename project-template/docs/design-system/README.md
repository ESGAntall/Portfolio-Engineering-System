# Design system (product layer)

Art direction và tokens **riêng app**. Kế thừa must-level từ `portfolio-engineering-system/portfolio/design-principles.md`.

## Điền khi có UI

- Brand / art direction (ngắn gọn)
- Color, typography, spacing (tokens hoặc link Figma)
- Component catalog (path trong codebase)
- Motion (nếu có)
- Locale / i18n UI rules (nếu có)

Skill gợi ý: `frontend-design` (screen), `portfolio-design-system` (đổi chuẩn chung).
