# Design system (product layer)

Art direction và tokens **riêng app**. Kế thừa must-level từ `docs/reference/design-principles.md`.

## Điền khi có UI

- Brand / art direction (ngắn gọn)
- Color, typography, spacing (tokens hoặc link Figma)
- Component catalog (path trong codebase)
- Motion (nếu có)
- Locale / i18n UI rules (nếu có)

**Skill trong repo app:** `frontend-design` cho screen/component/flow. Baseline chung đã có tại `docs/reference/design-principles.md` — tùy chỉnh art direction và tokens trong thư mục này (product layer). Chuẩn meta portfolio (`portfolio-design-system`) **không** dùng trong application repo.
