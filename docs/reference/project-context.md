Điền khi bootstrap. Dùng bởi skill `requirement-orchestrator` khi cần identity project — **không** yêu cầu mở portfolio meta repo.

| Field | Value |
|-------|--------|
| Project ID (registry) | _(điền, vd. noteai)_ |
| Display name | _(điền)_ |
| Remote repository URL | _(điền)_ |
| Portfolio rules/skills copy tag or commit | _(điền sau copy/bootstrap)_ |

## Ghi chú

- Đăng ký portfolio (nếu dùng): thao tác trong **portfolio meta repository** — không bắt buộc để làm việc hàng ngày trong repo này.
- Ràng buộc sản phẩm/kiến trúc: `docs/product/`, `docs/architecture/`, ADR trong `docs/decisions/`.
